# Engineering Projects

Embedded systems, signal processing and test automation projects by **Lokesh Reddy Sodanapalli**.

My engineering interests centre on connecting hardware, firmware and automated validation: controlling a physical test setup, analysing signals on a microcontroller and making test behaviour repeatable.

## Selected projects

| Project | Engineering goal | Technologies | Documentation |
